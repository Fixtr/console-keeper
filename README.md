# 콘솔지기 (Console Keeper)

## 누구를 위한 에이전트이고, 어떤 업무를 대신하는지

여행 일정 플래너 앱을 혼자 개발·운영하는 1인 개발자를 위한 에이전트입니다.

운영 중인 Google Cloud / Firebase 프로젝트 여러 개의 콘솔을 **매일 들어가서 눈으로
점검하는 일**을 대신합니다. 과거에 실제로 API 키 유출과 프로젝트 정지를 겪은 뒤,
"중요하지만 매일 하기는 귀찮아서 결국 사고 난 뒤에야 알게 되는" 점검 업무를
자동화하는 것이 목표입니다.

에이전트는 gcloud CLI로 각 프로젝트의 API 키 제한 상태를 조회해서, 제한이 풀린
키가 있으면 ⚠️와 함께 해당 콘솔로 바로 가는 링크를 한국어 보고서로 알려줍니다.
이상이 없으면 ✅ 한 줄로 끝납니다. 콘솔 설정을 바꾸지는 않는 읽기 전용
에이전트입니다.

### 구성
- `check.py` — 점검 스크립트 (gcloud CLI 호출, 판정, 한국어 보고서 출력)
- `CLAUDE.md` — 에이전트 지침 (보고 형식, 읽기 전용 규칙, 비밀 값 출력 금지)
- `projects.txt.example` — 점검 대상 프로젝트 목록 양식
  (실제 프로젝트 ID가 담긴 `projects.txt`는 git에 올라가지 않습니다)

### 사용법
```bash
cp projects.txt.example projects.txt   # 프로젝트 ID 기입
python3 check.py                       # 점검 실행 (gcloud 로그인 필요)
python3 check.py --self-test           # gcloud 없이 판정 로직만 검증
```

## 진행 상황

**지금 되는 것**
- 여러 GCP 프로젝트의 API 키 목록·제한 설정 조회 (gcloud CLI)
- 클라이언트 제한(HTTP 리퍼러/Android/iOS/IP)이 없는 키 탐지
- 한국어 보고서 출력 + 이상 시 콘솔 바로가기 링크, 종료 코드로 이상 유무 전달
- 판정 로직 셀프 테스트 (`--self-test`)
- 실제 운영 프로젝트 4개 대상 점검 검증 완료 (실제 경고 2건 탐지)

**아직 안 되는 것**
- 매일 자동 실행 + 알림 (Claude Code 스케줄 태스크로 연결 예정)
- 과금/쿼터 급증 탐지, Crashlytics 신규 오류 수 집계
- API 대상(apiTargets) 제한 검사 — 지금은 클라이언트 제한만 봐서, API 대상
  제한만 걸린 서버용 키가 ⚠️로 잡힐 수 있음 (오탐 가능성)
